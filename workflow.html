Архитектура проекта

Пять шагов
от URL до карты.

Понятная цепочка сервисов без передачи секретных ключей в браузер.

01
Ввод адреса

Пользователь отправляет URL

Форма проверяет формат адреса и передаёт его серверному маршруту Vercel.

URL
02
Сбор данных

Apify обходит публичные страницы

Actor получает страницы, внутренние ссылки, заголовки и глубину переходов.

API
03
Подготовка

Данные очищаются и сокращаются

Сервер убирает повторы и формирует компактный набор для языковой модели.

JSON
04
AI-анализ

OpenRouter направляет запрос к LLM

Модель группирует страницы и возвращает результат по заданной JSON-схеме.

LLM
05
Интерфейс

Сайт показывает структуру

Пользователь раскрывает разделы, читает обзор и изучает найденные связи.

UI
Серверная конфигурация

Закрытые переменные

APIFY_API_TOKENOPENROUTER_API_KEYOPENROUTER_MODEL

Значения хранятся только в настройках окружения Vercel и не передаются браузеру.
