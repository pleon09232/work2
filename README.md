# SiteScope — work2

Интерактивный многостраничный шаблон учебного сервиса, который в будущем будет:

1. принимать URL сайта;
2. запускать Apify Actor;
3. передавать собранные данные в LLM через OpenRouter;
4. показывать структуру сайта и краткий AI-обзор.

Сейчас внешние API намеренно не подключены. Анализатор показывает демонстрационные данные. Доступ к страницам защищён общей парольной авторизацией.

## Локальный просмотр

Для проверки серверной авторизации используйте Vercel CLI и задайте локальные переменные `SITE_PASSWORD` и `AUTH_SECRET`:

```bash
vercel dev
```

Обычный сервер статических файлов покажет интерфейс, но не запустит middleware и API входа.

## Страницы

- `/` — главная;
- `/analyzer.html` — форма и демо-результат;
- `/workflow.html` — будущая архитектура;
- `/about.html` — описание и статус проекта.
- `/login.html` — форма авторизации.

## Будущие переменные окружения

Скопируйте `.env.example` в `.env.local` и заполните значения только после реализации серверной части:

- `APIFY_API_TOKEN`
- `OPENROUTER_API_KEY`
- `OPENROUTER_MODEL`
- `SITE_PASSWORD`
- `AUTH_SECRET`

Настоящие ключи нельзя коммитить в GitHub или использовать в браузерном JavaScript.

После успешного входа сервер выдаёт подписанную `HttpOnly` cookie на семь дней. Пароль проверяется только в Vercel Function, а middleware закрывает основные страницы от прямого просмотра.

Подробный план интеграции находится в [`docs/integration-plan.md`](docs/integration-plan.md).
