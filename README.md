# SiteScope — work2

Интерактивный многостраничный учебный сервис, который:

1. принимать URL сайта;
2. запускает официальный Actor `apify/website-content-crawler`;
3. передаёт собранные данные в DeepSeek V4 Flash 0731 через OpenRouter;
4. показывает структуру сайта, анализ контента и предварительный SEO-аудит.

Доступ к страницам и серверным маршрутам анализа защищён общей парольной авторизацией.

## Локальный просмотр

Для проверки серверной авторизации используйте Vercel CLI и задайте локальные переменные `SITE_PASSWORD` и `AUTH_SECRET`:

```bash
vercel dev
```

Обычный сервер статических файлов покажет интерфейс, но не запустит middleware и API входа.

## Страницы

- `/` — главная;
- `/analyzer.html` — форма, прогресс и рабочий отчёт;
- `/workflow.html` — архитектура обработки;
- `/about.html` — описание и статус проекта.
- `/login.html` — форма авторизации.

## Переменные окружения

Скопируйте `.env.example` в `.env.local` и заполните значения:

- `APIFY_API_TOKEN`
- `OPENROUTER_API_KEY`
- `OPENROUTER_MODEL`
- `PUBLIC_SITE_URL`
- `SITE_PASSWORD`
- `AUTH_SECRET`

Настоящие ключи нельзя коммитить в GitHub или использовать в браузерном JavaScript.

После успешного входа сервер выдаёт подписанную `HttpOnly` cookie на семь дней. Пароль проверяется только в Vercel Function, а middleware закрывает основные страницы от прямого просмотра.

Анализатор ограничивает один запуск 50 страницами. Сначала применяется экономичный Cheerio crawler; для сайтов, полностью отрисовываемых JavaScript, может понадобиться переключение на adaptive crawler.
